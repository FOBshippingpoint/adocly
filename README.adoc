== Quickstart

* Using Adocly: https://fobshippingpoint.github.io/adocly

* Test your self:

. Install https://viteplus.dev/guide/[Vite+]
. Install dependencies:
+
[,sh]
----
vp install
----
. Start local server:
+
[,sh]
----
vp run frontend#dev
----
. Go to http://localhost:5173
. (Optional) Spawn server if you need real-time collaboration feature:
+
[,sh]
----
vp run backend#dev
----
